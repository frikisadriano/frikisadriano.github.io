# Portfolio — AHOUE Adriano Frikis

Portfolio de développeur web full-stack, en ligne sur **https://frikisadriano.github.io**.

Site statique (HTML, CSS, JavaScript), sans dépendance ni étape de build.

## Modifier le site

- `index.html` : textes, projets et contacts
- `style.css` : couleurs et mise en page (thème clair et sombre)
- `script.js` : numéro WhatsApp (constante `WHATSAPP`), filtres, fenêtre de détail, formulaire
- `assets/` : photo et captures des projets

Chaque modification envoyée sur la branche `main` est publiée automatiquement par GitHub Pages.
